# HealthTrackerApp

This repository is for the HealthTrackerApp Agile Software Development project.

## Purpose
Track development tasks, bug fixes, testing, and release preparation.
HEAL-8: Bug-fix work tracked for the HealthTrackerApp project.

## Frontend Development

The frontend provides the user interface for the HealthTrackerApp.
It is designed to help users interact with the application's health
tracking features. Frontend development should be tested to ensure
the interface works correctly and displays information clearly.
